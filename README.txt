BENJAMIN LOVELL PORTFOLIO — VERSION 2

OPEN LOCALLY
1. Double-click index.html, or open the folder in VS Code and use Live Server.

EDIT YOUR CONTACT DETAILS
- Open contact.html.
- Replace YOUR_EMAIL@example.com and @YOUR_HANDLE.
- Replace # links with full Instagram / YouTube / Vimeo links.

ADD YOUR SHOWREEL
- Open script.js.
- Set SHOWREEL_URL to your YouTube, Vimeo or other showreel URL.

CHANGE GALLERY IMAGES
- Put your images in assets/.
- In index.html, change the src="assets/..." values in the Selected Work gallery.
- JPG, PNG and WEBP are all suitable.

EDIT YOUR RESUME
- Edit resume.html for the website version.
- Benjamin-Lovell-Resume.pdf is the downloadable PDF included with this build.

PUBLISH FOR FREE
- GitHub Pages can host this static site for free.
- Upload the contents of this folder to a GitHub repository and enable Pages in repository settings.
- You can later connect a custom domain without rebuilding the site.
